# Design Systems and Tokens

## Design Tokens

- **Color tokens**: `color.background.primary`, `color.text.link`, `color.border.input`
- **Typography tokens**: `typography.heading.1.font-size`, `typography.body.leading`
- **Spacing tokens**: 4px base unit → `spacing.1` = 4px, `spacing.2` = 8px, up to `spacing.16` = 64px
- **Shadow tokens**: `shadow.sm`, `shadow.md`, `shadow.lg` (elevation levels)
- **Sizing tokens**: `size.input.height`, `size.icon.sm`, `size.avatar.lg`
- **Breakpoint tokens**: `breakpoint.sm` = 640px, `breakpoint.md` = 768px, `breakpoint.lg` = 1024px, `breakpoint.xl` = 1280px

## Token Naming Conventions

- **Category-Type-Item**: `color.text.primary`, `spacing.padding.md`
- **BEM-style**: `color-background-primary`, `font-size-heading-1`
- **Component-scoped**: `button.bg.primary`, `card.padding.default`
- **Alias-to-global mapping**: `color.background.brand` → `color.global.blue.600`

## Token Platforms

- **Style Dictionary**: Amazon's build-time tool; transforms tokens from JSON/JSON5 into platform-specific outputs (CSS custom properties, SCSS vars, Swift enums, Kotlin objects)
- **Design Tokens W3C Spec**: Standard format using `$value`, `$type`, `$description`; enables cross-tool interoperability
- **Theo**: Salesforce's token system supporting JSON → CSS/SCSS/Swift/Android
- **Cobalt**: Token-transformer focused on plugin ecosystems

## Component Libraries

- **Radix UI**: Unstyled, accessible primitives (Dialog, Popover, DropdownMenu, Select); headless + WAI-ARIA compliant
- **Headless UI**: Tailwind-aligned, unstyled components by Tailwind Labs
- **shadcn/ui**: Copy-paste component collection built on Radix + Tailwind; not a dependency, owned in codebase
- **Ark UI**: Headless components by Zag machine, framework-agnostic (React, Vue, Solid)

## Theme Specification

- **Light/dark**: `data-theme="dark"` on `<html>`; tokens swap via CSS custom properties
- **Brand inheritance**: Base theme → brand overrides: `--color-primary: var(--brand-color)`
- **High contrast**: Override layer for users requiring WCAG AAA contrast
- **Theme modes**: Tokens reference CSS custom properties that switch via attribute selector

## Documentation Tools

- **Storybook**: De facto standard; `*.stories.tsx` auto-register; Docs addon generates prop tables from TypeScript
- **Pattern Lab**: Atomic design documentation; molecule → organism → template → page
- **Docusaurus/Slate**: For design-guideline sites (usage guidelines, anatomy, behavior)

## Versioning Design Systems

- **Semver**: Patch for token value changes, minor for new components, major for breaking API changes
- **Changelog**: Auto-generated from commits/PRs grouped by type (feat, fix, breaking)
- **Release workflow**: Changeset-based (e.g., `@changesets/cli`) → version bump + publish

## Cross-Platform Token Sharing

- **CSS**: Custom properties via `:root { --color-primary: #0066cc }`
- **JS/TS**: Exported objects for runtime theming (`import { tokens } from '@design/tokens'`)
- **Swift**: UIColor/NSColor extensions auto-generated from tokens
- **Kotlin**: ColorRes, DpRes, TypographyRes objects generated by Style Dictionary
- **Flutter**: ThemeData objects from tokens via codegen
