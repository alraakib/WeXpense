# Tech Lead Reference

## Key Responsibilities
- Technical vision and roadmap
- Code review and quality standards
- Team mentorship and growth
- Architecture decisions (ADRs)
- Cross-team coordination
- Incident response leadership
- Stakeholder communication
- Technical debt management

## Estimation Techniques
- T-shirt sizes (XS-XL) for early/uncertain work
- Planning Poker for sprint planning (team consensus)
- Three-point (optimistic + pessimistic + most likely) for detailed tasks
- Affinity mapping for large backlog

## Code Review
- PR size: 200-400 lines optimal
- Review within 24 hours
- Focus on behavior over implementation
- Automate: lint, format, typecheck, CI

## Team Health
- DORA metrics: Deployment frequency, lead time, CFR, MTTR
- SPACE framework: Satisfaction, Performance, Activity, Communication, Efficiency
- Retrospectives: What went well, what to improve, action items
- 1:1s: Weekly, career growth, blockers, feedback

## Incident Response
| Severity | Response | Example |
|----------|----------|---------|
| SEV1 | Immediate (all hands) | Site down, data loss |
| SEV2 | <30 min | Feature degraded |
| SEV3 | <2 hours | Minor bug |
| SEV4 | <1 week | Cosmetic issue |
